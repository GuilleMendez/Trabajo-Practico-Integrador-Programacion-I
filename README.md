📝 Descripción del proyecto
Este trabajo práctico consiste en el desarrollo de una aplicación de consola en Python destinada a la gestión de información de países.
El sistema permite:

Registrar países

Actualizar datos

Buscar por nombre

Filtrar por población o continente

Ordenar por distintos criterios

Analizar información

Guardar los cambios en un archivo CSV

El programa utiliza un dataset inicial (CSV) del cual se cargan los datos, y luego cada función opera sobre esa estructura. Finalmente, un tablero interactivo permite al usuario elegir opciones del 0 al 11.

🖥️ Instrucciones de uso
El programa presenta un menú principal con opciones numeradas del 0 al 11.
El usuario debe seleccionar una opción y completar los datos solicitados.

El sistema incluye:

Validaciones de entrada

Manejo de errores

Reintentos automáticos con while True dentro de los try-except

Control de lectura/escritura del archivo CSV

La opción 11 guarda todos los cambios realizados.
La opción 0 permite salir del programa, ofreciendo antes la posibilidad de guardar.
